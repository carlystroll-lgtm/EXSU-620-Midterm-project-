# Supporting verification evidence

Collected November 7-8, 2026. This bundle accompanies the nine-page D7 verification report.

- `selected_angle_measurements.csv`: latest capture for each angle/trial. Repeats are labelled; selection is not proof that earlier attempts were invalid.
- `all_angle_attempts.csv`: every captured angle attempt, including out-of-tolerance results.
- `raw/`: captured telemetry, event records, experiment markers, review metadata and operator confirmations. Keys describing physical reference angles may be operator statements, not independently confirmed truth.
- `reviews/`: detailed evidence assessments, including provisional schedule comparisons and retained limitations. Relative references in these working reviews refer to the original verification folder; the corresponding files are in `raw/` or alongside this README.
- `protocol_1615_schedule_comparison.csv`: diagnostic comparison with planned timings. NOT an independently labelled ground-truth dataset.
- `figures/`: plots reproduced from measured records.
- `manifest.json`: file hashes for integrity checks.

Original videos are retained at their supplied local locations and are not embedded here. These records do not establish a complete pass of all requirements. The report marks reference limitations, unverified performance and intentional configuration deviations.
